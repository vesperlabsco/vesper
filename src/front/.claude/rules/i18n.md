# i18n

- Un namespace JSON par espace : `common`, `org-admin`, `clinic-admin`, `app` — dupliqué dans chaque dossier de langue (`en/`, `fr/`).
- Une clé de traduction utilisée dans l'espace `clinic-admin` va dans `clinic-admin.json`, pas dans `common.json`. `common.json` est réservé à ce qui est réellement partagé entre les 3 espaces (boutons génériques, messages d'erreur globaux, etc.).
- Ne jamais coder en dur du texte utilisateur dans un composant — toujours passer par la clé i18n, même pour du texte visiblement "temporaire".
- Ajouter une clé dans `fr/` implique de l'ajouter dans `en/` dans le même changement (pas de langue qui traîne en retard).
